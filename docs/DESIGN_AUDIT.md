# Аудит дизайна: `DESIGN.md` ↔ главная страница

Дата: 25.09.2026. Проверялись `DESIGN.md`, `.impeccable/design.json`, `src/App.tsx` и `src/App.css` (версия v0.2, до переноса главной в `src/pages/HomePage.*`).

## 1. Что совпадало

Главная страница в целом честно следовала `DESIGN.md` версии «Контур / тёплая редакция»:

- палитра «кофейная ночь + тёплая бумага + терракотовый сигнал» (`#0d0b0a`, `#f1e7db`, `#ff5a1f`);
- квадратная геометрия (0px), тонкие рамки, жёсткая тень только у hero-report;
- Manrope для текста, IBM Plex Mono для меток, Oswald для цифр;
- motion с учётом `prefers-reduced-motion`, остановка анимаций вне экрана.

## 2. Расхождения и проблемы

### 2.1. Между `DESIGN.md` и кодом

| # | Где | Что не так |
|---|-----|------------|
| 1 | `App.css`, весь файл | Токены объявлены локально в `.page-shell`, а не в `:root`. Около 80 цветов захардкожены hex-литералами мимо токенов (`#d7bdab`, `#f0d5c1`, `#b99b88` и т.д.), у многих почти одинаковые значения. Для новых страниц (каталог, профиль) переиспользовать палитру было нельзя. |
| 2 | `index.css` / `package.json` | Подключены 6 семейств шрифтов (Manrope, IBM Plex Mono, Oswald, Boldonse, Bitcount, Bebas Neue), в `DESIGN.md` описаны 5, а **Bebas Neue не используется вообще**. Правило «Two Voices Rule» на практике нарушалось: в одном блоке hero-отчёта встречались Manrope, Plex Mono и Oswald. |
| 3 | `.faith-line` (фон hero) | **Boldonse не содержит кириллицы.** Фраза «НЕ ВЕРИШЬ ИМ / ПОВЕРЬ НАМ» на деле рисовалась fallback-шрифтом Arial Black — дизайн-решение из `DESIGN.md` в браузере не работало. |
| 4 | `.report-company span` | Селектор задевал и `company-glyph`: буква «N» в квадрате hero-отчёта уменьшалась до 10px и прижималась к углу. |
| 5 | Hero-отчёт, карусель | Показатели NOVA Studio (88/100, «+12 за квартал») захардкожены прямо в JSX и расходились с данными дашборда (4.7 vs 88). Это нарушало «Honest Data Rule» из самого `DESIGN.md`. |
| 6 | Вкладки `report-tabs` | Декоративные «Обзор / Культура / Интервью / Зарплаты» выглядят как рабочие вкладки — прямое нарушение пункта Don't «не превращать подписи в неработающие вкладки». |
| 7 | Шапка | Кнопка профиля «АН» и колокольчик без функциональности (всплывающее «скоро будет доступно»). На мобильных вход был недоступен совсем (`.profile-button { display: none }`). |
| 8 | Навигация | Весь сайт — один компонент на 1000 строк с переключением `view` через `useState`: нет URL у профиля компании и каталога, не работает «Назад», ссылкой нельзя поделиться. |
| 9 | Страница каталога | Была заглушкой «появится следующим этапом». |

### 2.2. Между `DESIGN.md` и новым техническим заданием

ТЗ требует «спокойную, глубокую, корпоративно-технологичную» палитру: тёмно-синие, графитовые, пастельные акценты, без кислотных оттенков. Шрифты — Inter, Plus Jakarta Sans или Outfit. Стиль Clean Tech / Modern SaaS.

| Аспект | `DESIGN.md` (было) | ТЗ | Решение |
|--------|--------------------|----|---------|
| Палитра | тёплая кофейная + насыщенный терракотовый `#ff5a1f` | тёмно-синий/графит + пастель | перейти на blue-graphite |
| Акцент | `#ff5a1f` — яркий, почти неоновый на тёмном фоне | без «ядовитых» оттенков | стальной синий `#6f93dd`, текстовый вариант `#2d4f93` |
| Шрифт | Manrope + Oswald + Boldonse + Bitcount | Inter / Plus Jakarta / Outfit | **Inter** + IBM Plex Mono для меток |
| Фотографии | сепия | нейтрально | приглушённый монохром |
| Геометрия | 0px, «анти-SaaS» | Modern SaaS | оставить почти квадратную (0–2px) — это узнаваемая черта бренда и не мешает «официальному» тону |

> Plus Jakarta Sans и Outfit **не содержат базовой кириллицы** (только `cyrillic-ext`), поэтому для русскоязычного сайта из списка ТЗ подходит только Inter.

## 3. Что сделано (рекомендации → правки)

1. **Токены вынесены в `:root`** (`src/index.css`, префикс `--c-*`). Локальные имена в `HomePage.css` сохранены, но ссылаются на глобальные токены. Все тёплые литералы заменены.
2. **Палитра blue-graphite:** `--c-deep #0e1624`, `--c-canvas #eef1f5`, `--c-accent #6f93dd`, `--c-accent-ink #2d4f93`. Статусные цвета (good/warn/bad) приглушены и всегда идут с иконкой и подписью.
3. **Шрифты:** Inter Variable + IBM Plex Mono. Удалены пакеты Manrope, Oswald, Boldonse, Bitcount, Bebas Neue. Кинетическая типографика hero — Inter 900 (с кириллицей), прозрачность снижена до 0.22/0.32.
4. **Цвета графиков** проверены валидатором палитры: `#3a64b8` / `#a8742c` проходят проверки CVD, лёгкости и контраста 3:1 на белом.
5. **Роутинг** (`react-router-dom`): `/`, `/companies`, `/companies/:slug`, `/auth/callback`. Страницы грузятся лениво отдельными чанками (главный бандл 443 КБ вместо 582 КБ).
6. Исправлены селекторы глифов (п. 2.1.4), вход в шапке доступен и на мобильных, колокольчик-заглушка удалён.
7. `DESIGN.md` переписан под новую систему.
